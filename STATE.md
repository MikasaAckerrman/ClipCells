## Рекомендованный сценарий копирования (юзеру)
Тап по ячейке → оставаться в ClipCells, пока не появится «Скопировано N сообщений»
→ в Gboard открыть Буфер обмена и вставлять записи по порядку.

## Не проверено юзером
- Новый флоу (тап → ожидание 1-3с → Gboard-история)
- Удержание 2,7с / выбор 3×3 / Undo
- Экспорт/импорт, PIN/биометрия — не начаты (PRD backlog)
